# 星云教务 · 学生成绩管理系统

一个基于原生 HTML / CSS / JavaScript 实现的学生成绩管理单页应用（SPA）。无需后端、无需构建工具，浏览器打开即用。

## ✨ 功能特性

- **数据总览面板**：学生总数、班级平均分、班级最高分、待关注人数四项指标实时统计。
- **成绩分布可视化**：纯 CSS 绘制柱状图，支持在总分 / 语文 / 数学 / 英语之间切换，按 90–100、80–89、70–79、60–69、0–59 分段统计。
- **成绩排行榜**：按总分自动降序，展示前 4 名学生。
- **学生成绩表格**：
  - 添加 / 编辑 / 删除学生，弹窗表单内三科成绩实时预览总分；
  - 全局搜索与表格内搜索联动，`Ctrl / ⌘ + K` 快速聚焦搜索框；
  - 按状态筛选：优秀（≥270）/ 良好（240–269）/ 合格（180–239）/ 需关注（<180）；
  - 按总分升 / 降序或中文姓名排序。
- **数据校验**：成绩限定 0–100 整数、姓名非空与查重、错误信息就地提示。
- **数据导出**：一键将学生数据导出为 JSON 文件（Blob 下载）。
- **本地持久化**：基于 `localStorage`，刷新或关闭浏览器后数据不丢失。
- **体验细节**：Toast 操作反馈、`Esc` 关闭弹窗、空数据状态页、渲染前对用户输入做 HTML 转义以防 XSS。
- **响应式布局**：三档断点（1120px / 800px / 540px），桌面端侧边栏导航，平板与手机端自动折叠为图标栏并重排栅格。

## 🛠 技术栈

- HTML5 语义化结构
- CSS3：Flexbox / Grid / CSS Variables / 媒体查询
- 原生 JavaScript（ES6+）：DOM 渲染、事件委托、Blob 文件下载
- localStorage 本地存储

## 📁 项目结构

```
教务系统前端/
├── index.html   # 页面结构与单页入口
├── styles.css   # 全部样式（含响应式断点）
└── app.js       # 数据管理、渲染管线与事件处理
```

## 🚀 快速开始

无需安装依赖，直接用浏览器打开 `index.html` 即可运行；也可在当前目录启动一个静态服务：

```bash
# 任选其一
npx serve .
python -m http.server 8000
```

随后访问终端提示的地址（如 `http://localhost:8000`）。
